## Exact source shape

[AddBitvectorNatConversionFunction](../../../Source/DafnyCore/Verifier/BoogieGenerator.cs) at lines 1035-1058 emits distinct actual Function objects N and F and a standalone Axiom A. N has the effective semantic attribute bvbuiltin="bv2int". F is ordinary and has no Body. The producer does not attach A to F.DefinitionAxioms. For positive width W the exact equation is:

```text
forall b: B(W) :: { F(b) }
  ((0 <= F(b)) && (F(b) < 2^W)) && (F(b) == N(b))
```

A bounded source index may recognize this shape. It does not certify availability for a verification context. Match resolved object identities and complete typed syntax, never names or detached metadata:

- W is a resolved positive native word width in 1..4096. Validate that bound before computing the expected 2^W. F and N are distinct actual top-level Function objects in this same source program, each monomorphic with one word input and one Int output. Every formal is where-free; their actual formal/result identities are distinct. Each actual call has empty type instantiation, exactly the actual binder b as its argument by IdentifierExpr.Decl, the exact FunctionCall.Func reference, and Int result.
- F and N have no actual Body, DefinitionBody, DefinitionAxiom or OtherDefinitionAxioms. F has no function attributes. N has exactly the reviewed bvbuiltin="bv2int" attribute and independently satisfies the existing native declaration signature checks. An attribute cannot override a Body; an actual zero Body does not mean unsigned conversion.
- A is the same actual top-level Axiom object, A.CanHide is false, and its attributes are empty. A.Expr is exactly an unconditional Bool ForallExpr with no type parameters or quantifier attributes, one actual where-free word BoundVariable b, and no nested or additional quantifier.
- Its only trigger is positive, has Next==null, and contains exactly one F(b) term. The complete body is outer And(inner And(Le(0,F(b)),Lt(F(b),M)),Eq(F(b),N(b))), with exact Bool and Int operand/result sorts and M exactly 2^W. Every F/N reference and every binder declaration identity is checked. Guarded, reordered, additional or missing conjuncts, different binders, captures, existential formulas, extra/negative/missing trigger terms, and type instantiations do not supply this route.

Bound the top-level declaration scan by the existing 100,000-node ceiling and the candidate index to 64 exact F/N/A triples. Require at most one eligible triple per F; ambiguous duplicates fail admission rather than choosing one. The fixed-shape checks inspect only a constant number of expression nodes per candidate, and W bounds every range numeral to at most 1,234 decimal digits. These are explicit admission failures, never logical premises. A shape mismatch leaves the existing opaque-UF policy intact; it supplies no synthetic equality or range axiom.

## Direct roots and the availability premise

The first route uses only direct source calls inside an explicit owned raw AssertCmd.Expr, AssumeCmd.Expr or simple AssignCmd.Rhss. StateCmd containment is allowed only through the exact nested command identities already checked by [B3StructuredCfgCorrespondence](../../../Source/DafnyCore/Backends/B3/B3StructuredCfgCorrespondence.cs), lines 40-74 and UniqueCommandTree. Block, command, enclosing StateCmd chain, expression-root slot and child path belong to this same typed unit and source program. They are read-only reference evidence, not reconstructed names or token coordinates.

Do not infer this evidence from the mere presence of a Function in the program or from a global set of expression objects. A source expression object may be shared with a procedure specification: the active normalization invocation must be for the exact eligible raw command/root. Procedure requires/ensures, formal/global/local where clauses, havoc-generated constraints, call contracts/arguments, synthesized structured guards, and actual Body expansion do not acquire this first direct-root certificate. Their wrapper calls remain opaque or retain the existing Unsupported behavior. Pruning disabled does not widen this initial source-origin policy.

The required premise for each replacement is precise: the exact direct call is an expression occurrence of a raw source command/root retained in the source context corresponding to this already-validated G3 replay. A selected raw assertion remains; an unselected learning assertion is represented with its unchanged expression as an assumption; an unselected nonlearning assertion is absent. Ordinary raw assumptions and assignment roots remain under the existing command correspondence. The assertion origin must be the actual source AssertCmd referenced by the normalized Check, not a synthesized postcondition or callee-requirement Check that happens to carry a token or other anchor. For loops or repeated normalized anchors, bind the exact normalized occurrence and obligation role separately. No certificate transfers from one context mask to another.

This premise is sufficient for the pinned dependency argument. [ReadOnlyVisitor](https://github.com/erniecohen/boogie/blob/73a0e214a87df85fc058270268c1d0706fd05bc9/Source/Core/StandardVisitor.cs#L1046) visits AssertCmd.Expr, AssumeCmd.Expr and every assignment RHS; its block and StateCmd visitors visit those actual commands. [AxiomVisitor](https://github.com/erniecohen/boogie/blob/73a0e214a87df85fc058270268c1d0706fd05bc9/Source/VCGeneration/Prune/AxiomVisitor.cs#L18), [DependencyEvaluator](https://github.com/erniecohen/boogie/blob/73a0e214a87df85fc058270268c1d0706fd05bc9/Source/VCGeneration/Prune/DependencyEvaluator.cs#L39), and [ComputeDeclarationDependencies](https://github.com/erniecohen/boogie/blob/73a0e214a87df85fc058270268c1d0706fd05bc9/Source/VCGeneration/Prune/Pruner.cs#L25) give F -> A and A -> N. ## Proposed internal interface and two phases

Keep this state internal to normalization; no worker/schema or public verification-result change is needed. Suggested records are descriptions of planned APIs, not existing code:

1. Shape binds source Program, F, N, A, binder, W and declaration ordinals by reference identity. It is never a live-axiom receipt.
2. DirectCall binds Shape, unit, raw block/StateCmd path/command, expression root and source child path, exact typed NAryExpr, active normalization anchor and the newly returned opaque Ir.Application by reference. Capture it before rewriting. A per-call token prevents structural record equality or a reused source expression from supplying another occurrence's origin. Source-call and witness traversal have the existing 100,000-node and 128-depth bounds.
3. Availability binds that DirectCall and each actual IR occurrence path to the exact preliminary context mask, selected source identity set, retention role and unchanged selected definition set. All retained occurrences need their own mask-bound certification. Removed unselected nonlearning occurrences need none.

First normalize F through the existing opaque application route. Select guarded literal definitions with the unchanged source visibility analysis. Create preliminary contexts and run the existing exact ValidatePartition while every F application is still intact. Inventory occurrences with complete expression traversal, including word operations and let values/bodies. Selected checks, unselected learning assumptions and ordinary statements are distinguished from removed checks by this actual preliminary replay. Reject the extension if a selected literal-definition formula contains an uncaptured wrapper occurrence; no source-axiom conversion is added to the guarded-definition catalogue.

After independent certification in every context where an eligible occurrence survives, deterministically substitute just those certified F applications in the original normalized program with BitvectorToUnsignedInt at W, Start=End=0, Int result, and the recursively unchanged/lowered original word argument. Keep declarations, variable identities, statements, order, check IDs and learning flags. Retaining an unused F declaration is harmless and conservatively retains its resource charge; do not invent an N UF or any target axiom.

A separate narrow substitution validator compares preliminary original to substituted original by exhaustive constructors and child paths. The only allowed node replacement is an exact registered/certified F application with the exact unsigned operation and argument described above. Every other constructor, field, list length, type and source identity remains unchanged; a generic expression-equivalence exception is forbidden. The validator also checks exact correspondence between the preliminary and final context mask inventories and certification coverage, including copied occurrences and nested arguments. Recreate contexts from the substituted original using the identical already-selected definition sets. Existing ValidatePartition must then pass unchanged against that substituted original. Request hashes reflect the final programs, while masks and source identities remain the same.

Recheck final per-program node/depth/word/numeric/message bounds and all aggregate context bounds after substitution. The independent word-argument visitor repairs are prerequisites; this implementation does not edit those two owned visitor cases or claim their frozen omission has disappeared. Keep the candidate/witness/receipt counts bounded before allocation and retain complete program-message limits. Failed admission or certificate validation rejects the unit without adding a source assumption.

## Model argument and controls required before acceptance

For a source model of the corresponding retained context, the certified live A gives F(b)=N(b) for every native word. Pinned N is the unsigned word-to-Int primitive, so it has the target's same full carrier and value. Each certified replacement preserves expression value; A's existing range conjunct agrees with that carrier. Dropping A after its justified substitution does not assert a new fact. Existing command/check and replay correspondence then carry a source countermodel to a target countermodel. Thus normalized-valid implies source-valid, conditional on those existing correspondences and pinned primitive semantics. This English argument is not a mechanized end-to-end theorem or a verifier receipt.

Required controls include:

- Exact emitted F/N/A at widths 1, 3, 67 and the admitted boundary; high-bit unsigned values, round trips under original conversion guards, and wrong-value failures. The default additional-axioms option stays false. The optional round-trip axiom and all existing conversion/divisor/count checks remain unchanged.
- Missing/detached/duplicated A; forged metadata; hideable A; guarded, reordered, extra or wrong-range bodies; wrong FunctionCall.Func or IdentifierExpr.Decl; wrong binder/formal/result sorts or instantiation; extra/negative/missing triggers; attributes and actual zero Bodies on either function. No failed shape may gain native recognition.
- Selected-check-only, ordinary-assumption, assignment and nested StateCmd roots; unselected learning retention and nonlearning removal; one source call copied into multiple normalized occurrences; mixed masks with unrelated hide/reveal; absent roots and crossed mask receipts. Removing a nonlearning call must remove its receipt requirement, and it must never root another occurrence.
- A source NAryExpr shared between an eligible raw command and a procedure spec, a forged raw command/root reference, a spec-only conversion, callee-contract conversion, and a wrapper inside an actual Body. Membership elsewhere must not certify those invocations. Body-chain support stays separately unsupported/unreviewed.
- A malformed narrow-substitution witness must fail for an unrelated expression change, argument swap, width/type/operation change, check-ID or learning change, mask/definition replacement, omitted retained occurrence, or forged path. Budget tests must charge copied words and every final context.
- Satisfiable high-bit word and conversion contexts in which assert false still fails, alongside positive arithmetic identities and explicit negative/narrowing guards. Strict old corpus expectations and fresh complete checked-library/worker/actual-corpus receipts remain required.

This checkpoint adds no source assumptions, target axioms, option changes or acceptance claims. Full original bitvector/backend scope remains open beyond this smallest direct-source route.
