## Source capture and replay

`B3UnsignedWrappers` recognizes only the complete owned positive-width F/N/A shape. The bound is 64 distinct unambiguous triples, with widths in 1..4096 and the existing 100,000-node declaration/source-call index and 128-depth limits. It checks exact source Function, Axiom, binder and formal references, complete sorts/attributes/trigger/body syntax, absence of actual Bodies or definition metadata, and nonhideability. Shape mismatches retain opaque F; duplicate eligible equations and admission excesses reject the unit.

Before any unsigned substitution, `Command` enters a scope only for an exact owned raw AssertCmd, AssumeCmd or simple AssignCmd. Each scope indexes its own source expression paths, captures a newly returned opaque application by reference, and binds its actual normalized leaf-statement anchors. Sharing a source expression inside that root creates separate target witnesses; sharing it with a specification supplies no specification witness. StateCmd children use their own actual command identity and enclosing source chain. Block/command containment, source declarations and source formal identities are rechecked before replay certification. A second traversal has its own complete 100,000-node/128-depth ceiling: every captured exact root/child path must still contain the original NAryExpr, resolved Function, monomorphic Int signature and original argument reference; a direct identifier also retains its original declaration. The observed source artifact remains unchanged.

An eligible F reached outside those active scopes rejects with `b3_unsigned_wrapper`. This includes procedure specifications, global/formal/local where predicates, havoc-generated predicates, callee contracts/arguments, synthesized guards and loop-invariant initialization/preservation. Actual word Body chains retain the existing Body rejection; this checkpoint does not add a dependency-chain route. These are explicit fragment boundaries, never assumptions about the unsupported expression's value. An exact source shape does not widen root availability.

The normalizer then creates the unchanged preliminary G3 contexts and validates their exact partition while F is still opaque. Each retained occurrence is checked separately against its own context mask and IR child path. A selected original check, ordinary assumption/assignment, and unselected learning check replayed with the identical condition have distinct retention rules. A removed unselected nonlearning check contributes no occurrence. A structurally equal application cannot borrow a reference witness, and a context cannot borrow another mask's receipt. Selected definition formulas cannot acquire an uncaptured F substitution. Receipts have the existing 200,000 aggregate-node and 64 MiB aggregate-path ceilings; source witness paths have the 32 MiB message ceiling.

## Narrow substitution and conditional correspondence

Only applications certified everywhere they survive are deterministically rewritten as the typed native unsigned operation, with exact width, zero indices, Int result and recursively unchanged/lowered original word argument. No F/N name guesses, target N function or equality/range axioms are introduced. Keeping the unused original F declaration preserves its admission charge.

The independent validator compares every statement/expression constructor, list position and metadata field. Only the reference-bound certified F node can change constructor. Check IDs, learning, state/control order, variables, function/type declarations, source identities, masks, selected definition identities and every unrelated child are preserved. It validates both original/substituted programs and every preliminary/final context pair. Final contexts are reconstructed from the identical selected definitions and pass the existing partition validator unchanged. Complete output node/depth/word/message limits and context aggregate limits are rechecked after substitution. The source-round-trip option and original conversion-fit obligations remain unchanged.

The [English model argument](unsigned-wrapper-context-plan.md#model-argument-and-controls-required-before-acceptance) is conditional on the existing source-command/G3 replay correspondence. A retained direct source F call roots the exact F under the pinned read-only Pruner. The sole positive singleton trigger supplies F -> A; nonhideable A remains available and references native N. A therefore equates F with the same full unsigned word carrier/value used in the target. Every certified replacement preserves expression value in that corresponding retained source model, so dropping A after substitution enlarges the remaining target context. Target validity implies source validity under those explicitly stated correspondences and primitive semantics. This is an English argument, not a mechanized end-to-end proof or an arbitrary-native-split availability claim.
