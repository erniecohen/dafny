# Integrated structural gate: bound actual TRX interpretation to captured bytes

This supplements the immutable integrated583 English/data frame; its census, seven-stage vectors, three immutable compiled snapshots, all caps and false acceptance scopes stay unchanged. The new coordinator's per-suite TRX reader must capture one bounded raw TRX buffer before interpretation, compute the actual TRX receipt from that buffer, and parse that exact buffer with ElementTree.fromstring. Do not hash one path read and parse a later path read. The source/data/per-suite validation adaptation is outside the six unchanged ownership helper bodies.

Read only the fixed owned suite TRX paths after natural test-scope completion. Open the leaf with NOFOLLOW, NONBLOCK and close-on-exec, require a regular descriptor, admit its observed length at most16MiB, and detect short content, growth and before/after descriptor-identity changes under the current deadline. Each content request is at most65536 and the admitted remaining length; the separately admitted one-byte EOF/growth probe is explicit. The finite per-suite attempted-input bound is at most16MiB content plus one probe, with no retry to obtain an accepted buffer. Close the descriptor on every path. Support UTF-8 with an optional UTF-8 BOM and an absent or UTF-8 XML encoding declaration; reject other encodings. Prohibited DOCTYPE/ENTITY declarations, unsupported XML constructs, malformed documents and source/inventory mismatches reject. A captured buffer's length and SHA256 are the only bytes parsed and recorded as the actual TRX. Final path/output-inventory correspondence still must match that captured record; this is not an atomic execution-image or external-writer attestation.

Preserve strict exact result/definition/entry counts, unique and one-to-one IDs, current method/display/codeBase/source associations, passed/counter checks and actual ordered records. Capture or parser failure poisons the gate and preserves the original error as bounded diagnostic evidence; it never mints an accepted snapshot, retries a partial suite, invokes a worker, or changes an expected test row. No repository body is run during this English/source review.
