A missing metadata row could therefore leave the preceding library's context pending. That checkpoint and its static receipt remain historical source evidence; there is still no execution or identified offending asset.

For every sorted target-library entry, reset the pending context and publish the exact current library/version/target identity before the unchanged `assets['libraries'][library]` lookup. A lookup KeyError remains the primary qualification failure; observer faults remain separate evidence.

This changes diagnostic ordering only. Actual parsed-byte pins, immutable first snapshots, all byte caps, original process helpers/stages/workflow/inputs/fixtures/product, two-case expectations and 590/37 reuse-only claims remain unchanged.
